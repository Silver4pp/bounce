# Bounce

Mini game pantulan bola menggunakan Pygame.

## Fitur
- Bola pantul otomatis
- Kontrol paddle kiri/kanan (panah)
- Simple visual minimalis

## Cara Pakai
```bash
pip install -r requirements.txt
python src/main.py
```

## Struktur
- `src/main.py` — kode game
- `assets/` — gambar / suara (optional)
